# Wind Energy Feasibility Study — Mumbai, India (NASA POWER)

A technical case study that uses 44 years of daily NASA POWER data to 
(1) characterise the wind resource at Mumbai and 
(2) compare two one-day-ahead wind-speed forecasting models
in order to judge whether the site is suitable for small wind turbines.

**Author:** Kartikeya Kukreti — B.Tech., USICT

---

## Overview

| Item | Detail |
|---|---|
| Problem | Predict daily wind speed at 50 m (`WS50M`) and judge small-turbine feasibility |
| Site | Mumbai, India (19.076°N, 72.878°E) |
| Data | NASA POWER daily point data, 1 Jan 1981 – 31 Dec 2024 (16,071 days) |
| Models | SARIMA (with Fourier annual-cycle regressor) and Random Forest, plus a persistence baseline |
| Resource analysis | Two-parameter Weibull fit, wind power density, monthly climatology, power-law wind-shear extrapolation to 10 m |
| Evaluation | Chronological split (train 1981–2022, test 2023–2024), walk-forward one-step-ahead forecasting |

## Key results

Test set: 2023–2024, 731 days.

| Model | MAE (m/s) | RMSE (m/s) | R² | MAPE (%) |
|---|---|---|---|---|
| Persistence (baseline) | 0.658 | 0.899 | 0.719 | 13.97 |
| SARIMA + Fourier annual cycle | 0.607 | 0.820 | 0.766 | 13.01 |
| **Random Forest** | **0.582** | **0.785** | **0.785** | **12.39** |

Wind resource at 50 m: mean 4.95 m/s, Weibull k = 2.95, c = 5.54 m/s, mean power density about 105 W/m². The estimated mean speed at 10 m is 3.58 m/s (Hellmann exponent 0.207).

**Conclusion:** the site is marginally feasible for small, low-cut-in-speed turbines, especially in the June–September monsoon peak, and not attractive for utility-scale wind farms.

## How to reproduce

Requires Python 3.10+.

```bash
pip install pandas numpy scipy scikit-learn statsmodels matplotlib
```

Run from the repository root:

```bash
python project/code/analysis.py
```

This writes all figures to `project/figures/` and result tables to `project/data/` (`model_comparison.csv`, `monthly_climatology.csv`, `ws50m_descriptive_stats.csv`, `resource_summary.txt`). The SARIMA walk-forward loop refits nothing but updates the filter state daily, and takes a few minutes.

To rebuild the report:

```bash
cd latex
pdflatex main.tex && bibtex main && pdflatex main.tex && pdflatex main.tex
```

## Data source and provenance

Data come from the NASA **Prediction Of Worldwide Energy Resources (POWER)** Project (https://power.larc.nasa.gov/), catalogued at https://data.nasa.gov/dataset/prediction-of-worldwide-energy-resources-power. POWER values are derived from the MERRA-2 reanalysis, not from on-site anemometers.

The CSV in this repository was extracted from a publicly available GitHub compilation of NASA POWER exports ([marco-hening-tallarico/Nasa-Climate-Data](https://github.com/marco-hening-tallarico/Nasa-Climate-Data))

Please acknowledge the NASA POWER Project if you reuse the data.
